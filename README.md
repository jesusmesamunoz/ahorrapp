# Ahorrapp · páginas web

Páginas estáticas de la app personal Ahorrapp:

- `callback.html`: devuelve el control a la app tras autorizar el acceso en el banco. Solo reenvía un código de un solo uso, que no sirve sin la clave privada guardada en el iPhone.
- `privacidad.html` y `condiciones.html`: política de privacidad y condiciones de uso.

No contienen datos, claves ni código de la app.
